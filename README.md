# 爆笑村民大逃亡 / Villager Mayhem: Party Escape

第一批多人派對 Obby：支援 1～8 人、回合狀態、同步起跑、三個順序檢查點、掉落復位、即時排名、終點、DNF 結算與記憶體內 leaderstats。

第二批加入六種排名加權派對道具、鍵盤／手把／觸控操作、統一移動修飾器、3～5 秒跑道外懲罰，以及卡通村莊賽道、道具箱與裝飾。

第三批加入爆笑村莊廣場、休閒／排位 Queue、伺服器記憶體牌位、Solo Tower01、統一 Profile 與 ReturnToLobby 流程。玩家必須主動選擇模式，不再自動加入競速。

第四批加入版本化 DataStore Profile、Session Lock、Autosave、金幣商店、外觀裝備、安全 Marketplace 收據、每日獎勵及 OrderedDataStore 全球排行榜。Studio 無 API 權限時會使用明確標示的記憶體測試資料。

## 開發

執行 `start-rojo.bat`，在 Roblox Studio 用 Rojo 外掛連線後同步。建議使用 Test > Start Server，以 2～4 名玩家測試；單人 Play 也可運作。
